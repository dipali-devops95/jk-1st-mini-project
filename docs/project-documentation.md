# Static Website Hosting Using Continuous Delivery

## 1. Project Overview

This project demonstrates the deployment of a static website on Amazon S3 using a Continuous Delivery pipeline integrated with GitHub and Jenkins.

The objective is to automate website deployment whenever the website source code is updated in the GitHub repository.

## 2. Project Objectives

- Create a static website using HTML and CSS.
- Store website source code in GitHub.
- Configure Amazon S3 for static website hosting.
- Integrate Jenkins with GitHub and AWS.
- Automate website deployment using a Jenkins pipeline.
- Verify the deployed website using its hosting endpoint.

## 3. Technologies Used

- Amazon Web Services (AWS)
- Amazon S3
- GitHub
- Jenkins
- HTML and CSS
- AWS IAM

## 4. Project Architecture

Developer → GitHub → Jenkins Pipeline → Amazon S3 → Live Website

## 5. Implementation Steps

1. Create a GitHub repository.
2. Develop the static website.
3. Configure an S3 bucket for website hosting.
4. Configure the required AWS IAM permissions.
5. Configure Jenkins and the required AWS credentials.
6. Create a Jenkins pipeline for deployment.
7. Trigger the pipeline and verify the deployment.
8. Update the website and verify the delivery process.
